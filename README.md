A single original funny line for make.fun's "One Line, One Laugh" bounty. The program writes one line to `/output/entry.txt`: meditation goes wrong when the brain treats silence like an open mic night and performs a greatest-hits set of your most embarrassing moments. Funny on its own, punchline lands inside the line, no setup needed.

## Run it

```sh
node main.ts
```

This writes the line to `/output/entry.txt` (creating `/output` if needed). Deterministic: the same line on every run. Requires Node 22 or later, no dependencies, no network.
